# Einstellungen

| Einstellung | Beschreibung |
| --- | --- |
| Beitrags-ID | Die ID des anzuzeigenden Beitrags — die 24-stellige Zeichenfolge am Ende der Beitrags-URL. Pflichtfeld. |

Statt der reinen ID kann auch die vollständige Beitrags-URL eingefügt werden;
das Widget liest sich die ID selbst daraus heraus. Das ist die bequemste
Variante: die URL des gewünschten Beitrags in Staffbase öffnen, aus der
Adresszeile kopieren und in das Feld einfügen.
