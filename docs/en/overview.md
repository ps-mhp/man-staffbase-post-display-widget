# Post Display

The Post Display embeds a single, previously published
Staffbase post at the location where the widget is
placed on a page. This is useful for prominently featuring an important post
on another page—such as a homepage, a
team page, or a campaign landing page—instead of simply linking to it.

The language version displayed matches the reader’s
language setting (first the document’s language, then the browser’s). If
the post is only available in another language, that language is shown instead of
nothing at all.

The post is retrieved based on the reader’s session—so
their usual reading permissions automatically apply, no more and no
less.
