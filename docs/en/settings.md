# Settings

| Setting | Description |
| --- | --- |
| Post ID | The ID of the post to be displayed—the 24-character string at the end of the post URL. Required field. |

Instead of just the ID, you can also enter the full post URL;
the widget will extract the ID from it automatically. This is the most convenient
option: open the URL of the desired post in Staffbase, copy it from the
address bar, and paste it into the field.
