# Settings

| Setting | Description |
| --- | --- |
| Post | The post to display. Required field. Select from the **Posts** list (the 100 most recent posts, with channel and date; the search filters by title and channel). If it’s not there, select **Enter ID or URL** and enter the full post URL or the 24-character string at the end of that URL. Any entry that does not contain a readable ID will not be accepted. |

The settings open in a full-screen window. The tabs **Desktop**,
**Tablet**, and **Mobile** at the top show the post as readers
see it.

There are no other settings to configure. The layout, order of elements, and
language are determined automatically.
