# FAQ

**Question:** The widget displays "No post ID configured" — what should I do?

Answer: Enter the post ID (or the full post URL) in the
widget settings. Without an ID, the widget doesn’t know which
post to display.

**Question:** Why does a reader see a different language version than
expected?

Answer: The widget displays the language that matches the language setting of the page
or the reader’s browser—not necessarily the language in
which the post was originally written. If the post is only available in a
different language, that language is displayed so that “nothing” is never shown.

**Question:** Can I use this widget to display posts that the reader
is not actually supposed to see?

Answer: No. The post is retrieved based on the reader’s session
— so their normal reading permissions apply exactly as they would otherwise. If the
reader lacks the necessary permission, the post remains invisible even through this widget.
