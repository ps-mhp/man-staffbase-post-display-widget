# Visualizador de entradas

El visualizador de entradas permite mostrar una entrada de Staffbase ya publicada
en otro lugar: basta con colocar el widget en una página, introducir el
ID de la entrada y esta aparecerá directamente allí para su lectura, en lugar de solo
como un enlace.

Casos típicos: repetir una noticia importante en la página de inicio,
incrustar una entrada en una página de equipo o de campaña, crear una página de destino a partir
de entradas existentes.

## Qué se muestra

**Título, resumen y cuerpo del texto** de la entrada, incluidas las imágenes del texto.
No se incluyen los comentarios, los «me gusta», los archivos adjuntos, los datos del autor o autora y
la fecha, ni el enlace a la entrada original. Si necesitas ambos, añade
además un enlace normal a la entrada.

## Información importante

- El widget **no copia nada**. Siempre muestra el estado actual de la
  publicación: si la publicación se edita posteriormente, la visualización
  aquí también cambia.
- **Los permisos se mantienen.** La entrada se carga cuando el
  lector inicia sesión. Quien no tenga permiso para ver la entrada original, tampoco
  la verá aquí. Por lo tanto, el widget no es un atajo para eludir a los grupos objetivo
  .
- **Idioma:** se muestra la versión lingüística que se corresponde con el idioma de la página o
  del navegador. Si la entrada solo está disponible en otro idioma, se
  muestra ese —en lugar de no mostrarse nada—.
