# Paso a paso

## Incrustar la publicación

1. Abre la página de inicio para editar y selecciona el widget **Ver publicar**
   Arrastra el lugar deseado. 
2. En la configuración de **Post** selecciona la lista **Post ...** 
   y selecciona la publicación. Cada entrada menciona el título, el canal y la fecha; 
   Las últimas publicaciones están en la parte superior. 
3. Guarda y previsualiza.

   Copia la barra de direcciones del navegador. 
2. En la lista selecciona **Introduce otro ID de publicación ...**. 
3. Pega la dirección copiada en el campo. El ID lee el widget
   — la cadena de 24 dígitos al final de la dirección no tiene por qué ser
   se puede elegir a mano.

ID de la publicación". Este aviso también aparece en la
página publicada — es decir, nunca publiques con un campo vacío.
