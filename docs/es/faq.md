# Preguntas frecuentes

**Pregunta:** El widget muestra «No se ha configurado ningún ID de entrada», ¿qué puedo hacer?

Respuesta: Introduce el ID de la entrada (o la URL completa de la entrada) en la
configuración del widget. Sin el ID, el widget no sabe qué
entrada debe mostrar.

**Pregunta:** ¿Por qué un lector ve una versión en otro idioma distinto al
esperado?

Respuesta: El widget muestra el idioma que se ajusta a la configuración de idioma de la página
o del navegador del lector — no necesariamente el idioma en
el que se redactó originalmente la entrada. Si la entrada solo está disponible en otro
idioma, se mostrará este para que nunca aparezca «nada».

**Pregunta:** ¿Puedo utilizar este widget para mostrar también entradas que el
lector en realidad no debería ver?

Respuesta: No. La entrada se recupera con la sesión del lector,
por lo que se aplican exactamente sus permisos de lectura habituales. Si no tiene
el permiso, la entrada seguirá siendo invisible incluso a través de este widget.
