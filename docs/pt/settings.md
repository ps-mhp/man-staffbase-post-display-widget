# Configurações

| Cenário | Descrição |
| --- | --- |
| Post | A postagem a ser exibida. Campo obrigatório. Selecione **Selecionar post ...** da lista (as 100 postagens mais recentes, com canal e data). Se estiver faltando, selecione **Insira outro ID de postagem ...** e insira o endereço completo da postagem ou a sequência de 24 dígitos do final desse endereço. |

Não há mais nada para configurar. Exposição, ordem dos elementos e
A linguagem surge automaticamente.
