# Exibição de postagem

O anúncio da postagem retoma uma postagem já publicada na Staffbase
outro lugar: Você coloca o widget em uma página, seleciona o
Publique a partir de uma lista — e a postagem aparecerá lá diretamente para leitura, em vez de apenas
Como um link. 

Ocasiões típicas: repita uma mensagem importante na página inicial,
Incorpore uma postagem em uma página de equipe ou campanha, crie uma landing page a partir de
contribuições existentes. 

## O que é exibido

**Título, teaser e texto principal** do post — incluindo as imagens no texto. 
Comentários, curtidas, anexos, autor e
Data e um link para o post original. Se você precisar dos dois,
Além disso, um link normal para o post. 

## Importante saber

- O widget **não copia nada**. Ele sempre mostra o estado atual do
  Postagem: Se a postagem for editada posteriormente, a tela também mudará
  Aqui. 
- **As permissões permanecerão.** A contribuição será feita com o registro do
  pessoa lendo. Se você não puder ver o artigo original, você verá
  Ele também não está aqui. Então o widget não é um atalho para grupos-alvo
  Câmbio. 
- **Idioma:** A versão do idioma que corresponde ao idioma da página ou 
  do navegador. Se o artigo estiver disponível apenas em outro idioma, será
  esses — em vez de nada.
