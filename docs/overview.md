# Beitrags-Anzeige

Die Beitrags-Anzeige bettet einen einzelnen, bereits veröffentlichten
Staffbase-Beitrag an der Stelle ein, an der das Widget auf einer Seite
platziert wird. Das eignet sich, um einen wichtigen Beitrag prominent auf
einer anderen Seite zu wiederholen — etwa auf einer Startseite, einer
Team-Seite oder einer Kampagnenlandingpage — statt nur darauf zu verlinken.

Angezeigt wird die Sprachfassung, die zur Spracheinstellung der lesenden
Person passt (zuerst die Sprache des Dokuments, dann die des Browsers). Gibt
es den Beitrag nur in einer anderen Sprache, wird diese gezeigt statt gar
nichts.

Der Beitrag wird mit der Sitzung der lesenden Person abgerufen — es gelten
also automatisch deren übliche Leseberechtigungen, nicht mehr und nicht
weniger.
