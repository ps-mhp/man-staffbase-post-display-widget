# Impostazioni

| Impostazione | Descrizione |
| --- | --- |
| ID post | L'ID del post da visualizzare — la stringa di 24 caratteri alla fine dell'URL del post. Campo obbligatorio. |

Al posto del solo ID è possibile inserire anche l’URL completo del post;
il widget ne ricava automaticamente l’ID. Questa è l’opzione più comoda:
aprire l’URL del post desiderato su Staffbase, copiarlo dalla
barra degli indirizzi e incollarlo nel campo.
